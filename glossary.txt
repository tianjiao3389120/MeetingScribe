# 领域词表 —— 作为 whisper 的 initial prompt 注入，纠正术语识别
#
# 写法要点：
#   · 写成通顺的中文句子，不要写成散词罗列，whisper 对前者响应明显更好
#   · 总长控制在 170 字以内（模型 initial prompt 上限约 224 token，会被截断）
#   · 优先放"高频且总被听错"的词。每次发现新错词，回来补进去，越用越准
#   · 以 # 开头的行会被忽略
#
# 下面是一份示例，请按自己团队的实际术语替换。

技术评审会议。术语：Agent、Syslog、SIEM、Hotfix、UAT、CVE、POC、Oracle、备机、\
主备、拓扑图、日志、告警检出、可执行文件、脚本文件、文件落盘、扫描、\
内存违规访问、反弹shell、异常登录、入侵检测、闭环、需求、哈希。
